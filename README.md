# EVD RESPONSE DIGITAL TWIN

面向南方科技大学演示的中文埃博拉输入性疫情应急响应桌面推演。当前版本实现 Module 1–3 的连续可玩序列，用于验证 2.5D 数字孪生、跨模块状态持久化、确定性分支与宏观/现场视图同步。

## 本地运行

需要 Node.js 22 或兼容版本。

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm test
npm run build
```

构建产物位于 `dist/`，Vite `base` 使用相对路径，适合静态部署。

## 当前范围

- 真实 Bundibugyo 背景简报，和虚构深圳推演明确分层。
- 联合指挥公共壳、情境指标、导航和离线确定性状态。
- 共用同一 2.5D 医院场景的急诊分诊、患者拒绝和首次报告三段事件。
- 三个二选一决策形成 8 条可区分路径，并由时间调度器同步场景、指标、时间线和渐进决策树。
- 离线 SVG 深圳全局态势与医院现场推演无损切换；城市节点直接读取 Module 1 持久状态。
- Module 1 完成后经深圳全局态势进入 Module 2，连续完成转运、采样、初筛响应与复核确证。
- 城市地图渐进显示患者转运、标本转运和响应协同网络，并继续区分“需评估人员、风险接触者、疑似病例与确诊病例”。
- Module 3 以聚合调查指挥、航班暴露复核和跨区域协查为主，管理 126 人首轮调查名单、7/18/39 航班风险分类与基于个体最后暴露时间的 21 天监测状态。
- 调查簇、跨区域协查线和病例轨迹均不表示疾病传播；系统明确区分“接触、有效暴露、密切接触者和感染”。
- 本地确定性态势摘要，无 LLM 或 API 依赖。
